ISSUE-107 resolved

現象: 通常起動で画面全体に赤い枠（タグ ROI）が高速点滅。日本語訳（タグ OCR）が出ない。

原因:

  • 動画の毎フレーム差分で ROI が大量発生し、枠位置が毎回入れ替わる。
  • 設定 preview.show_roi_boxes / overlay.show_roi_boxes がオンだと OCR ではなく生 ROI デバッグ描画になる。
  • ブラウザ UI や映像の動きも「変化領域」として検出される。

対処: ラベル安定化（保持 1.5s・最小 2 ヒット）、描画 4Hz スロットル、画面下帯の字幕候補フィルタ、デフォルト min_roi_area 引き上げ、ROI デバッグのデフォルト off。
