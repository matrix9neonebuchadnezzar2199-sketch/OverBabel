ISSUE-101 解決済み

Phase 0 · 2026-05-19

現象

ERROR: Package 'overbabel' requires a different Python: 3.14.0 not in '>=3.11,<3.13'

開発 PC に Python 3.11 が無く、py -3.11 も失敗。既定の python は 3.14。

原因

pyproject.toml の requires-python = ">=3.11,<3.13" が 3.14 を拒否。

対処

  • requires-python = ">=3.11" に緩和（CI は引き続き 3.11）。
  • README に「3.11 推奨・CI は 3.11」と明記。

再発防止

本番・配布は Phase 7 で 3.11 固定 venv / PyInstaller を推奨。開発マシンは 3.14 でも editable install 可能にする方針を維持。
